Where it stands. A brake, not yet a detector.

Slice 2, dev (4 Nov 2026), real bug fixes from open-source Python projects. Of 20 wrong fixes written by a coding agent, Tracefix gave 6 a counterexample, but only 1 of those 6 rests on the agent’s own mistake; 4 still reached L2. Of 85 correct fixes, 8 got a false alarm.

0 of 7 release gates hold, so Tracefix is not released, and not yet good enough to gate merges on its own.

AI proposes. Code decides.

A model may write the tests and pick the attacks. Every level comes from running code: an exit code, a diff or a counter. Some of what runs was written by a model, and the receipt says which.

COUNTEREXAMPLE
Proof against the fix: an input that breaks it, a regression, a weakened test, or the bug isn’t fixed.
L0
Not reproduced, the tests could not run, or tampering was detected.
L1
Reproduced: a test fails before the fix and passes after it.
L2
L1, and the tests guard the fix: revert it or plant bugs in it and they notice.
L3
L2, and every behaviour change the diff observed is explained.
L4
L3, and a full Break My Fix attack found nothing. No real correct fix has reached L3 yet: 0 of 85 in Slice 2, dev (4 Nov 2026).

L4 means we tried hard to break it and nothing broke. It never means “this is correct”.

Put a fixture’s real receipt through the ladder

Point it at a fix.

Give it the commit before the fix, the commit with it, and the issue. On real fixes a live run took 3.7 minutes at the median (16.5 minutes at the 90th percentile) and writes a receipt that is safe to post as a PR comment. What a pull request gets: a check, a comment and the receipt as JSON.

Pre-alpha. Tracefix needs Python 3.11.4+, git 2.32+ and an Anthropic API key; your code and the issue are sent to Anthropic’s API. Not released yet: the repository opens on release, so until then the clone works only for collaborators. Not on PyPI: the commands install it from a clone into your project, so the project must allow Python 3.11.4+. Without uv: pip install ~/tracefix, then drop uv run. Project on an older Python (3.9 or later): uv tool install ~/tracefix and add --python .venv/bin/python.

Talk to me

Not released yet: the GitHub repository opens on release.

Does it fix my bug?+

No. It’s the friend who reads your fix and asks “what if the string is empty?”

Is it an AI code reviewer?+

No. Models write test code. Whether anything passed is decided by running it.

Does it raise false alarms?+

Sometimes. On the latest benchmark of real fixes, 8 of 85 correct fixes got a finding that was not a real bug. Every finding comes with a pytest file you can run yourself. If a receipt is wrong, tell me.

Is it safe on untrusted pull requests?+

Fork pull requests run only after a maintainer adds a label, and only with strict isolation (Linux with bubblewrap). The job that posts results never holds the API key.
